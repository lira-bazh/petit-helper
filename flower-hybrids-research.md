# Гибриды цветов: найденные сведения

Проверено 10 октября 2026 года в локальном клиенте Petit Planet:
`live_0.95`, revision `1217551`, каталог `F:\GAMES\PetitPlanet Game`.

## Подтверждено игровыми текстами

1. Для скрещивания нужно посадить рядом цветы **одного вида** и поливать их каждый день.
2. С наступлением нового дня на **соседних свободных клетках** могут появиться новые цветы.
   Новый цвет и само появление растения вероятностны.
3. Полив **гостями или NPC-соседями** повышает вероятность появления нового оттенка.
4. Новую расцветку дают только **определённые сочетания оттенков**.
   Полив сам по себе не делает любую пару подходящей.
5. После нескольких сборов цветы редких расцветок **деградируют до обычной расцветки
   того же вида**.

Из этих текстов нельзя установить точные проценты, число сборов до деградации,
допустимость диагонального расположения или наличие скрытых генов. Эти значения
не следует добавлять в базу как подтверждённые.

## Результат разбора BLK

`00000002.blk` содержит бандл с сериализованным файлом:

```text
CAB-ef2eeed697e1a3f1e5bdfb870fdfe5cc
```

В нём **54 941 объект `MiHoYoBinData`**, один `IndexObject` и один `AssetBundle`.
Это объясняет, почему поиск только по обычному `TextAsset` ничего не находил.
Типы объектов: `MiHoYoBinData` — `1208`, `IndexObject` — `1210`.

Каждый `MiHoYoBinData` содержит массив байтов с префиксом длины uint32 little-endian.
Часть массивов содержит JSON, часть — gzip, скомпилированный Lua или двоичные таблицы.
`IndexObject` сопоставляет числовой ключ ресурса с FileID, PathID и размером массива.
Сопоставление ключей этого индекса с именами `FlowerDropCfg.bytes` и
`FlowerPointPoolCfg.bytes` пока не установлено.

Некоторые полезные PathID внутри указанного CAB:

| PathID | Содержимое |
| ---: | --- |
| 4460 | Задание 7117: один вид цветов, ежедневный полив, возможность редкой расцветки |
| 40502 | Задание 7116 с тем же описанием |
| 24543 | Задание 7115: обратиться к Гленну за сведениями о выращивании цветов |
| 51345 | Диалог Гленна 711501 о скрещивании |
| 27111 | Диалог Гленна 711701 после получения редкой расцветки |
| 52120 | Граф обучения 620, «花杂交» |

Для продолжения поиска нужно разбирать объекты `1208` и индекс `1210`, а не искать
имена таблиц в сырых CAB или ограничиваться типом `49` (`TextAsset`).

## Чтение длинных строк ed.obb

Ранее исследовательский декодер корректно читал короткие названия, но повреждал часть
длинных описаний. Для этой версии игры байты длины строки участвуют во всех четырёх
байтах ключа:

```ts
const keys = [
  0x57 ^ (length & 255),
  0x02 ^ ((length >>> 8) & 255),
  0x35 ^ ((length >>> 16) & 255),
  0x01 ^ ((length >>> 24) & 255),
];
```

Порядок байтов строки зеркальный; индекс ключа определяется зеркальной позицией,
а центральный байт строки нечётной длины использует ключ 0. Уточнение ключа позволило
прочитать полный русский и английский текст обучения без искажений.
`scripts/find-missing-recipes.mts` читает только короткие названия до 240 байтов,
поэтому его существующий алгоритм для этих названий не менялся.

## Статус конкретных комбинаций

Проверяемая выгрузка из того же `GenerateAssets/ed.obb`, что используется для рецептов,
сохранена в [flower-sources.json](flower-sources.json). В ней сопоставлены все 93 цветка
из каталога, включая 51 результат-гибрид. Для каждого цветка сохранены игровые ID
растения, цветка и бутона, английские и русские названия, смещения записей предметов,
локализации и таблицы стадий, а также исходные поля этой таблицы.

```sh
pnpm exec node scripts/find-flower-sources.mts '/mnt/f/GAMES/PetitPlanet Game'
```

Скрипт обновляет только `flower-sources.json`. Поле `source` содержит
`GenerateAssets/ed.obb`, `live_0.95`, revision `1217551`. Таблица стадий находится
в корневом поле `241`, таблица предметов — в поле `318`.
Это источник идентификаторов и названий, а не подтверждение рецептов скрещивания.
Для связей родителей поле `breeding.status` установлено в `not-confirmed`.
Имеющиеся родители из базы сохранены отдельно в `existingDatabaseParents`.

В `src/lib/flowers.json` остаются 51 результат: у 24 указаны родители, у 27 — нет.
Новые конкретные сочетания родителей и результата из клиента пока не подтверждены.
Имеющиеся 24 комбинации также не следует считать заново проверенными этим исследованием.
Файл `flowers.json` в этом поиске не изменялся.
